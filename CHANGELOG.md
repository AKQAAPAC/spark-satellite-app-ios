# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - Initial release

- Connection-aware weather demo (status bar: Good / Low / No data; rain map gating; `-SimulateConstrainedPath` for testing).
- Location-based weather via Open-Meteo and Core Location; RainViewer radar map.
- Also verified on **Xcode 27** / iOS 27 SDK (deployment target remains iOS 26.0; satellite behaviour unchanged).
- Maintained by AKQA.
